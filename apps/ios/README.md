# 5WaveFlow Live for iOS

PHASE C용 자리입니다. SwiftUI 앱과 WidgetKit 확장은 macOS/Xcode에서 생성하며, PHASE A/B 동안 웹·Android와 공유할 API 계약은 `packages/market-data`에 먼저 정의합니다.

예정 기능과 서명·TestFlight 준비 절차는 [`../../docs/PHASE_C_D.md`](../../docs/PHASE_C_D.md)를 참고하세요. iOS는 지속 실행형 라이브 월페이퍼를 제공하지 않고, 정적 차트 이미지 저장과 시스템 정책을 따르는 위젯을 제공합니다.
