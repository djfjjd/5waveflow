# Market-data release gate

5WaveFlow Live는 가짜 가격이나 합성 캔들을 사용하지 않습니다. 다만 공개 API에 기술적으로 접근할 수 있다는 사실이 앱스토어에서 데이터를 상업적으로 재배포할 권리를 자동으로 부여하지는 않습니다.

## Binance

- 현재 웹과 Android 개발 빌드는 Binance 공개 Spot market-data API를 사용합니다.
- 스토어 제출 전 Binance 약관과 브랜드/데이터 사용 조건을 최종 검토하고, 앱의 캐싱·표시·재배포 방식이 허용되는지 문서화해야 합니다.

## Upbit

- Upbit가 게시한 데이터 이용 안내에는 사전 동의 없는 상업적 이용, 재배포, 가공·판매 및 타인의 투자 판단을 돕는 서비스 이용 제한이 명시되어 있습니다.
- 따라서 BTC/KRW는 현재 개발 미리보기 기능입니다. 정식 출시 전 두 가지 중 하나가 필요합니다.
  1. Upbit로부터 해당 사용 방식에 대한 서면 승인을 받는다.
  2. 상업적 표시 권한이 확인된 공급자로 교체하고 API 계약을 유지한다.
- 승인이 확인되지 않으면 출시 빌드에서 BTC/KRW를 제거해야 합니다.

법무 검토와 공급자 승인 여부는 코드 테스트로 검증할 수 없으므로 별도의 출시 차단 항목으로 관리합니다.
